# 自定义主题

主题编辑器用于在终端用户界面（Terminal User Interface，TUI）中调整配色，并直接预览效果。本指南介绍如何从已有主题开始修改，保存为自己的主题，以及撤销修改或删除主题。

编辑过程中的配色会实时预览，但不会自动保存。只有点击主题编辑器中的“保存”，修改才会写入主题文件，并在下次启动时继续生效。若希望直接编写 YAML 文件或查询配色字段，请参阅[主题文件参考](../../reference/themes.md)。

## 打开编辑器

1. 按 **F9**，或点击底栏的 `f9 主题`，打开主题列表。
2. 选择列表底部的“修改主题…”，打开停靠在主界面旁的主题编辑器。
3. 在编辑器顶部的下拉列表中选择要修改的主题。此操作只切换编辑对象，不会更改当前应用的主题。

编辑器旁保留当前对话，可以观察配色对文字、工具卡片和其他界面元素的影响。

编辑器打开期间，通过 F9、`/theme` 或设置窗口切换应用主题会受到限制。要更换编辑对象，使用编辑器顶部的下拉列表；要切换日常使用的主题，先关闭编辑器。

## 调整并预览颜色

编辑器按 `Colors`、`Buttons`、`Borders` 等分组列出颜色。编辑器使用字段名标识配色项，例如 `primary`（主色）、`background`（整体背景）。

1. 点击要修改的颜色块，打开颜色选择器。
2. 对于普通主题，在 `RGB / HSV` 中选择或输入颜色，也可以切换到“256 色”选取颜色。ANSI 主题提供 `ANSI` 和“256 色”两种选择方式，ANSI 颜色的实际显示由终端配色决定。
3. 调整时，主界面会实时预览。确认效果后点击“确认”，把这项修改保留在编辑器中；点击“取消”或按 **Esc**，放弃本次颜色选择器中的修改。

背景色和面板配色（`background`、`surface`、`panel` 和 `boost`）必须保持不透明，因此颜色选择器不提供这些字段的透明度调整。

## 撤销与重置

根据要撤销的范围，选择对应操作：

| 操作 | 结果 |
| --- | --- |
| 颜色选择器中的“恢复” | 恢复到打开这次颜色选择器时的值 |
| 编辑器中的“撤销”／“重做” | 撤销或重做已经确认的编辑操作 |
| 已修改字段旁的“↺”重置按钮 | 将这一项恢复为本次载入该主题时的值 |
| “全部重置” | 将所有字段恢复为本次载入该主题时的值 |

## 保存主题

1. 在编辑器中点击“保存”。
2. 在“保存主题”窗口中填写主题名称。
3. 点击“保存”。出现保存成功通知后，主题会立即应用，并记住本次选择。

主题名称须满足以下要求：

* 不超过 100 个字符，以英文字母或数字开头，只使用英文字母、数字、点、下划线和连字符，不能以点结尾。
* 不填写 `.yaml` 或 `.yml` 扩展名。
* 基于内置主题修改时，须使用新名称另存；基于用户主题修改时，名称与原名称完全一致（含大小写）时会覆盖原文件，使用新名称则另存。重名检查不区分大小写。
* 不能使用 Windows 设备名，如 `CON`、`NUL`、`COM1`～`COM9` 或 `LPT1`～`LPT9`，也不能使用这些名称后接点和后缀的形式，如 `CON.dark`。

## 关闭或更换编辑对象

切换编辑对象或点击“关闭”时，如有未保存的修改，会询问是否放弃。选择“放弃修改”将丢弃修改并继续操作，选择“取消”则继续编辑。

关闭编辑器后，界面恢复为当前应用的主题。

## 删除用户主题

“删除”会移除该主题文件和当前未保存的修改。内置主题不支持删除。

在编辑器顶部选择用户主题，点击“删除”，核对确认窗口中的主题名称后再次点击“删除”。删除当前已应用的主题后，iCode 会切换到默认主题 `chrys`。
