# 配置 iCode 设置

iCode 设置控制界面外观、默认智能体、会话、工具、通知和部分安全选项。本指南介绍如何在终端用户界面（Terminal User Interface，TUI）中完成这些基础配置，并确认修改何时生效。

如需直接编辑 `settings.yaml` 或通过环境变量配置，请参阅[iCode 设置文件参考](../../reference/settings.md)，了解文件位置、设置键和来源优先级。

## 设置窗口

### 打开设置窗口

设置窗口只能在智能体空闲时打开。

使用以下任一方式打开“设置”窗口：

- 按 **F10**。
- 点击界面底部的 `f10 设置`。
- 在输入栏中输入 `/settings`，按空格键或 **Enter** 显示标签页列表，然后选择要打开的标签页。

也可以用 `/settings <tab>` 直接打开标签页：

| 标签页 | `<tab>` | 主要设置 |
| --- | --- | --- |
| 通用 | `general` | 外观、输入与更新 |
| 模型与智能体 | `models` | 默认智能体、模型用途与请求重试 |
| 安全 | `security` | 审批、项目信任、诊断与遥测 |
| 会话 | `sessions` | 会话标题、存储与回滚 |
| 工具 | `tools` | 文件搜索、图片、网络工具、智能体提问、工具详情显示与工作区通知 |
| 通知 | `notifications` | 通知开关、方式与事件 |

例如，输入 `/settings security` 可直接打开“安全”标签页。

### 修改与生效时间

修改会随操作自动保存。输入框中的修改可按回车提交，也会在切换到其他设置或关闭窗口时提交。按 **Esc** 关闭窗口不会撤销已经提交的修改。

设置窗口右下角的状态提示说明修改何时生效；有多类待生效修改时，会同时显示相应提示。

| 状态提示 | 生效时机 |
| --- | --- |
| “修改即时保存” | 修改已保存，且没有需要在关闭窗口或重启后才生效的修改 |
| “修改将在关闭时生效（重载）” | 按 **Esc** 关闭“设置”窗口后生效 |
| “修改将在当前轮次结束后生效” | 有轮次或工作流正在运行时替代“修改将在关闭时生效（重载）”；关闭“设置”窗口且运行结束后生效 |
| 提示有多少项修改需重启后生效 | 修改已经保存，但必须退出并重新启动 iCode 后才会生效 |

下文各表的“生效时间”列列出每项设置的通常行为。

### 通用

| --- | --- | --- |
| 主题 | 切换 TUI 使用的主题。需要调整配色或创建自定义主题时，请参阅[自定义主题](themes.md)。 | 立即 |
| 界面显示语言 | 只改变 iCode 界面文案，不改变会话内容、模型输出语言或已有记录。也可输入 `/language` 切换界面显示语言。| 立即 |

#### 显示偏好

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| 默认展开思考 | 默认关闭（`ui.chat.show_thinking`）。开启后，模型服务以可读文本返回模型的思考时，新的思考在模型写出时于回复上方完整展开；关闭后只显示一行，滚动显示最新内容。无论开关，模型转入工具调用或回复后，思考都会折叠为一行，显示思考的开头。可以随时点击思考查看完整内容。服务只以加密形式返回的思考不会显示。修改后，对话中已有的思考保持原来的展开状态。 | 立即 |
| 默认展开工具详情 | 默认关闭（`ui.chat.tool_groups_expanded`）。开启后，新出现的工具组默认展开；关闭后默认折叠，只显示摘要和正在执行的操作。可以随时点击工具组展开详情。 | 立即 |
| 自动折叠已完成轮次 | 默认开启（`ui.chat.fold_finished_turns`）。成功回复后，将思考、工具调用和中间回复收起到一个按类别统计工具调用的标题下，例如 `12 次工具调用：8 次读取 · 4 条命令`；没有工具或轮次属于压缩历史时使用**执行过程**。用户消息、中途补充和最终回复始终可见。点击标题可切换单个片段；只用键盘时，输入 `/fold` 可统一收起或展开过程块、工具组、思考和工具调用之间的文字。错误、中断以及崩溃恢复的最后一轮保持可见；没有可见最终回复的轮次不自动折叠。已有折叠块保留你的选择。 | 之后完成的轮次及之后打开的会话 |
| 全彩图片 | 默认开启（`ui.chat.image_graphics`）。在 Ghostty、kitty 和 iTerm2 3.7.5 及以上版本中，对话里的图片（例如附带的截图和工具返回的图片）以终端自身的分辨率全彩显示；在 WezTerm、VS Code 和 Windows Terminal 1.22 及以上版本中，以每个字符格 10×20 像素显示。VS Code 只有在开启 `terminal.integrated.enableImages` 且没有关闭 GPU 加速（`terminal.integrated.gpuAcceleration`）时才显示。通过 SSH 连接时，如果远程主机上设置了 `COLORTERM=truecolor`（例如写在它的 shell 配置文件中），Ghostty、kitty 和 iTerm2 也会全彩显示图片。为了判断运行在哪个终端中，iCode 启动时会询问终端；如果终端始终不回应，启动最多会延迟一秒半。在其他终端中、在 tmux、screen 或 Zellij 中，或关闭此设置时，图片以彩色色块绘制，每个字符格显示两个像素。在 WezTerm、VS Code 和 Windows Terminal 中，对话滚动时图片显示为彩色色块，停止滚动后变清晰。如果在 Windows Terminal 中图片仍显示为色块，请从 Windows Terminal 的标签页启动 iCode，而不是从 Windows 在 Windows Terminal 中打开的控制台窗口启动。 | 重启后 |

#### 输入

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| 保存提示词历史 | 跨会话保存提交过的输入，供后续复用。主界面未被其他窗口覆盖时，按 **Ctrl+R** 会在输入栏上方打开历史提示词列表，直接输入文字即可检索，最相关的提示词排在前面；再按 **Ctrl+R**、上下键或 **Page Up**、**Page Down** 可在列表中移动；鼠标单击记录，或用上下键选中记录后按回车，会将该提示词复制到输入栏。提示词历史记录文件 `prompt_history.jsonl` 保存在：macOS 和 Linux 的 `~/.chrys/`，或 Windows 的 `%APPDATA%\chrys\`。关闭此设置不会删除该历史记录文件，只是不再读取，按 **Ctrl+R** 会提示提示词历史已关闭；重新启用并重启 iCode 后，仍可读取该历史记录文件中的记录。若要清理历史，请删除该历史记录文件；删除后无法恢复。 | 重启后 |

未打开建议列表时，**上箭头**和**下箭头**会逐行移动光标，包括长文本自动折行形成的行。只有在输入内容的首行按上箭头，才会调出更早的提示词。浏览历史时，只有在末行按下箭头，才会调出更新的提示词；越过最新一条后会恢复原来的草稿。

### 安全

#### 审批

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| 默认审批模式 | 设置下次启动 iCode 时默认使用的审批模式，不影响当前会话。窗口中只提供 `manual` 和 `auto`；如需在当前会话中绕过审批，请使用 `/approval bypass`。当前会话的模式切换及各模式区别请参阅[配置审批模式](./approval.md)。 | 设置立即保存，下次启动生效 |
| 自动审查策略 | “直接审查”（默认）由模型整体判断操作是否安全；“逐项风险检查”发现删除文件、发布代码等风险时，会请你确认。只在自动模式下生效。详见[选择自动审查方式](./approval.md#选择自动审查方式)。 | 关闭设置窗口后 |
| 人工审批超时（秒） | 默认 `0`（不超时），正数表示等待的秒数，负数调整为 `0`。适用于 TUI 和 ACP 人工审批，超时后拒绝本次调用。 | 重启 iCode 后 |

#### 项目信任

项目设置、项目钩子和项目 Skills 都随你打开的仓库而来，因此默认都不加载。工作目录中有未加载的项目设置、钩子或 Skills 时，iCode 会弹出提示，说明需要勾选哪一项。

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| 加载项目设置 | 读取当前工作目录的 `.chrys/settings.yaml`，应用其中的项目级设置，例如请求重试、自动生成会话标题和工作目录通知。可配置的键及覆盖限制见[项目级设置](../../reference/settings.md#项目级设置)。 | 关闭窗口后 |
| 加载项目钩子 | 决定是否加载当前工作目录 `.chrys/hooks` 中的 Hooks，不影响用户级 Hooks。创建和验证钩子请参阅[配置和编写 Hooks](../extensions/hooks.md)，完整配置字段见 [Hooks 配置参考](../../reference/hooks.md)。 | 关闭窗口后 |
| 加载项目 Skills | 决定是否加载当前工作目录 `.agents/skills` 中的 Skills，不影响你自己的 Skill 目录。详见[安装和使用 Skills](../extensions/skills.md)。 | 关闭窗口后 |

#### 诊断

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| 捕获模型原始 HTTP 请求 | 记录模型请求和响应，以便排查问题。**日志可能以明文包含 API 密钥、完整提示词和模型回复**，因此建议仅在排查时开启，并妥善保管日志文件；排查完成后，应及时关闭该设置并重启 iCode。日志文件 `llm_raw_http.jsonl` 保存在当前会话文件夹中；查找该文件夹的方法请参阅[查找会话 ID 和会话保存位置](../daily-use/sessions.md#查找会话-id-和会话保存位置)。 | 重启后 |

启用原始捕获后，需要完全退出并重新启动 iCode，恢复出问题的会话，再发送一次请求。日志在发送请求时创建；只勾选开关不会捕获当前进程的请求。

iCode 会根据结构化错误详情区分请求被拒绝和临时服务故障，即使网关改写了 HTTP 状态码，也会在聊天错误中保留服务提供方的解释。已识别的内容拦截和账户额度不足会停止 iCode 的自动重试循环；提供商 SDK 可能在返回错误之前已经重试过 HTTP 请求。

| 服务或网关 | 识别的错误详情 | 处理方式 |
| --- | --- | --- |
| [New API](https://github.com/QuantumNous/new-api) 及兼容中转服务 | `sensitive_words_detected`、`prompt_blocked`，以及 Anthropic 兼容端点使用的 `new_api_error` 消息形式 | 内容过滤拦截，包括被包装成 HTTP 500 的情况 |
| [阿里云百炼 / DashScope](https://www.alibabacloud.com/help/zh/model-studio/error-code) | `DataInspectionFailed` / `data_inspection_failed`；`Arrearage` | 内容过滤拦截；账户额度不足 |
| [火山方舟](https://console.volcengine.com/ark/region%3Acn-beijing/docs/error-codes) | `SensitiveContentDetected` 和文档中明确列出的输入、输出内容策略错误码 | 内容过滤拦截 |
| [OpenRouter](https://openrouter.ai/docs/api_reference/errors-and-debugging) | 精确的 `error_type`、审核 metadata 和预算 `limit_source` | 在 Chat Completions、Anthropic Messages 和 Responses 错误格式之间保留具体的拒绝、额度、限流或服务故障分类 |

对于非流式 Chat Completions，即使 HTTP 状态是 200，`choices[].error` 中的错误也会使整个响应失败：部分回答不会作为成功结果接收，工具调用不会执行，已报告的 token 用量仍会保留。只有 `finish_reason: "error"` 而没有错误详情时，按可重试的服务故障处理。

当响应内的错误没有 `code` 时，iCode 会使用原生 `type` 分类：例如，`billing_error` 和 `authentication_error` 会停止自动重试，`overloaded_error` 仍可重试。已识别的 canonical `error_type` 仍具有更高优先级。

普通 500/502/503 错误仍可重试；没有内容拦截证据的 403 仍归为鉴权或权限问题。OpenRouter 临时的 `openrouter_in_flight_budget` 响应在带有正数 `Retry-After` 时可重试，账户或工作区预算耗尽则不重试。如果普通任务内容遭到拦截，可以携带请求 ID 联系服务提供方排查：响应可能不包含具体命中内容，客户端无法仅凭状态码推断。

#### 遥测

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| OpenTelemetry 导出 | 启用遥测，记录追踪、日志和指标。关闭时，另外两项不会使 iCode 保存或发送遥测数据。 | 重启后 |
| 遥测端点 | 设置接收遥测数据的收集器地址。未通过设置或环境变量配置任何端点时，仅在本地保存追踪和日志；配置任一端点后停止本地保存，发送失败时也不会回退到本地。 | 重启后 |
| 遥测中包含敏感数据 | 额外记录提示词、模型回复、工具参数和工具结果，影响本地保存和远端导出；工具耗时指标也可能包含工具参数。启用前请确认数据去向和访问权限。 | 重启后 |

遥测数据的含义、保存位置、端点优先级和收集器连接方法见 [OpenTelemetry 参考](../../reference/opentelemetry.md)。

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| 图片大小上限（KB） | 发给模型的一张图片的文件最大可为多大，取值 32 到 3072 KB，默认 256。图片在请求中以文本形式发送，占用的大小比文件本身多约三分之一。你附加的、智能体查看的或 ACP 客户端发送的图片超过上限时，会压缩为不超过上限的 JPEG；图片文件本身不会被修改。每轮对话和每次重试开始前，会话中之前发送的、超过上限的图片也会同样压缩，会话保留压缩后的版本；因此 MCP 工具返回的图片从下一轮对话或下一次重试开始才会压缩。带图片的请求因过大而失败时（例如网关返回 HTTP 413 错误），调低上限后重试。上限越低，模型从每张图片中看到的细节越少。 | 关闭窗口后 |

#### 网络搜索

以下设置作用于包含网络工具的智能体；网络工具默认关闭，参阅[配置网络工具](./web-tools.md)。智能体配置文件自行设置的模式、结果数或超时，会覆盖该智能体的对应设置。项目设置不能修改这些设置。

| 设置项 | 效果与必要说明 | 生效时间 |
| --- | --- | --- |
| 网络搜索模式 | `auto`（默认）允许包含网络搜索的智能体使用该工具。未配置搜索提供方的智能体会把搜索请求发送到第三方服务 Exa 的公开搜索端点，参阅[网络请求的去向](./web-tools.md#网络请求的去向)。`off` 关闭网络搜索。智能体配置文件指定了模式时，以配置文件为准。 | 关闭窗口后 |
| 每次网络搜索的结果数 | 智能体未指定数量时，每次搜索返回的结果数，范围 1～20，默认 8。 | 关闭窗口后 |
| 网页读取模式 | `on`（默认）允许包含网页读取的智能体按 URL 读取页面。`off` 关闭网页读取。智能体配置文件指定了模式时，以配置文件为准。 | 关闭窗口后 |
| 网络代理地址 | 仅供网络工具使用的 `http://` 或 `https://` 代理，不含凭据和路径。留空表示直接连接。网络工具忽略 `HTTP_PROXY` 等代理环境变量。 | 关闭窗口后 |
| 网络代理 DNS | 设置代理后由谁解析主机名。`local`（默认）在本机解析，并在连接前检查每个地址。`remote` 把主机名交给代理解析（fake-IP 代理需要这样做），拦截私有地址的工作也随之交给代理；参阅[使用 fake-IP 代理](./web-tools.md#使用-fake-ip-代理)。未设置网络代理地址时不起作用。 | 关闭窗口后 |
| 自定义搜索端点 | 智能体配置文件中自定义搜索端点的授权项，写成 JSON 数组，每项形如 `{"url": "...", "credential_env_names": ["..."]}`。 | 关闭窗口后 |
| 网络搜索私有网络来源 | 即使解析到私有地址，网络搜索也可以访问的来源，写成 JSON 数组，例如本机 SearXNG 可写 `["http://127.0.0.1:8080"]`。 | 关闭窗口后 |
| 网络搜索明文 HTTP 来源 | 网络搜索可以通过明文 `http://` 访问的来源，写成 JSON 数组。 | 关闭窗口后 |

这些值在保存前按网络工具使用的同一套规则检查，被拒绝的值会说明错在哪里。清空列表字段即表示空列表。网络搜索超时、网页读取超时与词元预算，以及网页读取的来源列表不在窗口中显示，需在 `settings.yaml` 中设置（参阅[网络工具](../../reference/settings.md#网络工具)）。

#### 询问用户

| --- | --- | --- |
| 在对话中显示提问 | 开启后，智能体的提问直接显示在对话中；关闭后，提问显示在弹出窗口中。 | 关闭窗口后 |

#### 常规
