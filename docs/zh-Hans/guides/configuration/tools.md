# 配置工具

内置工具为智能体提供访问文件、搜索内容、执行 Shell 命令以及使用其他 iCode 功能的能力。本指南介绍如何在终端用户界面（Terminal User Interface，TUI）中为智能体启用或停用内置工具类别。

MCP 服务器提供的工具不属于内置工具，需要在 [MCP 配置](../extensions/mcp.md)中单独管理。[Python 扩展](../extensions/python-extensions.md)中的工具在同一个“工具”标签页的“扩展”下启用。

需要查询智能体配置和 Hooks 中使用的工具类别值及具体工具名称时，参阅[工具类别和名称](../../reference/tool-kinds-and-names.md)。

## 打开工具配置

在输入栏中输入 `/agents tools`，打开当前智能体的“工具”标签页。如需修改其他智能体，可在左侧列表中选择。

## 选择内置工具

每个选项对应一类内置工具，根据智能体需要完成的任务启用相应类别：

| 工具类别 | 可完成的操作 | 配置建议 |
| --- | --- | --- |
| 读取文件系统 | 读取文件和查看图像（PNG、JPEG 或 WebP） | 需要分析项目文件时启用；只有所选模型支持视觉输入时，智能体才能使用查看图像工具 |
| 写入文件系统 | 创建、覆写和精确编辑文件 | 仅在智能体需要修改文件时启用 |
| 文件搜索 | 搜索文件内容，或按名称模式查找文件 | 需要在项目中定位代码和文件时启用 |
| 网络搜索 | 查找网页链接和摘要；除非智能体配置文件指定了其他提供方，否则使用 Exa（exa.ai） | 需要查询最新文档、发布信息等外部资料时启用。搜索词会发往该外部服务，并可能带有对话中的内容，请注意数据与隐私安全 |
| 网页读取 | 按 URL 读取页面文本 | 需要阅读搜索到的页面或你指定的页面时启用 |
| Shell | 在子进程中执行终端命令 | 需要运行构建、测试或其他命令时启用 |
| 询问用户 | 在任务进行中请求补充信息或让用户作出选择 | 适合 TUI 和 ACP 会话；无界面命令行模式（`icode run`）不会向智能体提供此工具 |
| 文档转换器（PDF、Office） | 将 PDF、DOCX、PPTX、XLSX 和 XLS 转换为 Markdown；当前使用的模型支持图片输入、智能体已启用“读取文件系统”工具类别时，还可提取 PDF、DOCX 和 PPTX 中的图片供智能体查看；XLSX 和 XLS 只转换文本与表格 | 需要读取这些文档格式时启用 |
| 待办事项 | 用实时清单跟踪多步骤任务 | 适合步骤较多、需要显示进度的任务 |

每个智能体都可以使用 `sleep` 工具，因此列表中没有它的选项。智能体用它暂停任务，最长 3600 秒；TUI 中会显示可提前跳过的倒计时。

勾选需要启用的类别，取消勾选不需要的类别，然后点击“保存”。

如果修改的是当前会话正在使用的智能体，新工具配置会从后续请求开始生效。

iCode 自带的智能体都没有启用网络搜索；它与只搜索本地文件的“文件搜索”不同。“网页读取”是单独的开关。未配置搜索提供方时，搜索请求会发往 Exa 的公开搜索服务。启用前，请参阅[配置网络工具](./web-tools.md)，了解请求的去向、审批和网络限制。

## 使用“询问用户”工具

“询问用户”工具用于在任务进行中请求补充信息或让用户作出选择。一次提问可以包含 1～5 个问题，支持单选、多选和自由文本。

默认情况下，问题显示在弹出窗口中。如果弹窗遮挡了需要查看的会话内容，可以点击“在对话中回答”，将当前提问切换为在对话中显示；此操作仅对当前提问生效。如果希望后续提问默认在对话中显示，请在[配置 iCode 设置](./settings.md)中开启“在对话中显示提问”。

在 TUI 中，多个问题会显示在同一个提问窗口中。可以切换问题标签，填写各个问题后，在汇总页检查回答并统一提交。

等待回答的时间由[配置 iCode 设置](./settings.md)中的“询问用户超时（秒）”设置控制。

## 按需配置工具

工具配置决定智能体可以使用哪些能力。配置专用智能体时，建议仅启用完成任务所需的工具类别。

例如：

- 只分析代码的智能体可以启用“读取文件系统”和“文件搜索”，不启用“写入文件系统”和 Shell。
- 修改代码并运行测试的智能体通常需要启用“读取文件系统”“写入文件系统”“文件搜索”和 Shell。
- 处理不受信任的项目时，应谨慎启用 Shell 和“写入文件系统”。

启用工具只表示智能体可以调用该能力；需要审批的操作仍按当前审批模式处理。有关审批请求和确认方式的详细说明，请参阅[配置审批模式](./approval.md)。

对于文件系统、搜索和 Shell 工具，相对路径会以当前[工作目录](../daily-use/workspaces.md)为基准，Shell 命令也默认在当前工作目录中运行。切换工作目录后，这些相对路径和命令的默认工作目录会随之改变。工作目录是默认操作位置，并不表示工具只能访问工作目录内的路径；操作能否执行还取决于工具参数、需要审批时是否获得批准，以及运行 iCode 的系统用户权限。

命令输出很多时，智能体会看到输出的开头和结尾；条件允许时，iCode 会把输出保存到会话目录。命令输出超过 32 MiB 时，iCode 只保留开头和结尾部分，中间部分不会保存在任何地方，结果中会告诉智能体有多少内容没有保留。

## 在后台继续运行的命令

Shell 命令到达时间上限时如果仍在运行，不会被停止，而是转到后台继续运行。这样开发服务器、文件监视程序等可以一直运行，智能体则继续后面的工作。智能体会得知命令输出保存在哪里，以及如何停止这条命令。一个会话最多同时有 32 条命令在后台运行：已有 32 条时，到达时间上限的命令会被停止，已结束的命令留下仍在运行的程序也会被停止。需要等待后台命令时，智能体使用 `sleep`：它的某条后台命令结束时，`sleep` 会提前结束；对于主智能体，你发送新消息时 `sleep` 也会提前结束。

命令也可能在到达时间上限之前转到后台：

- 命令 60 秒内没有任何输出，也几乎不占用 CPU，例如等你在浏览器中完成登录的登录命令。只有命令的时间上限超过 60 秒时才会这样。
- 命令的 shell 已经结束，但它启动的程序仍在运行，例如用 `&` 启动的服务器。智能体同时会得到命令的退出码。

只有命令启动的所有程序都结束后，命令才算结束。因此，如果命令使用的工具会留下一个辅助程序继续运行（例如构建服务器），这条命令也会转到后台，命令被停止时这个辅助程序随之停止。在 Windows 上，命令打开的浏览器或编辑器如果原本没有在运行，命令被停止时也会随之关闭。

后台命令在以下情况停止：

- 在 TUI 中以及通过 ACP 客户端使用时，主智能体转到后台的命令会跨轮次继续运行，每一轮都会提醒智能体哪些命令仍在运行。子智能体或工作流节点转到后台的命令，会在它完成时停止。
- 会话结束时，所有后台命令都会停止：开始新会话、切换到其他会话、删除会话或退出 iCode（包括直接关闭终端窗口）时都是如此。使用 `icode run` 时，后台命令在本次运行结束时停止。
- 打断智能体会停止它正在等待的命令，但不会停止已经转到后台的命令。
- `/rollback` 会停止被丢弃轮次启动的命令。命令转到后台之后修改的文件，`/rollback` 不保证能够恢复。

如果命令启动的程序自行脱离了这条命令（例如某些工具用 `-d` 选项启动的服务），iCode 无法停止它们，会话结束后它们会继续运行。

如果 iCode 没来得及停止后台命令就结束了（例如崩溃，或被 ACP 客户端直接结束），在 macOS 和 Linux 上这些命令会继续运行。下次打开 TUI 时，iCode 会列出仍在运行的命令，询问是否**停止**它们；选择**忽略**则让它们继续运行。ACP 客户端再次启动 iCode 时，iCode 会直接停止之前的 ACP 会话留下的命令，不再询问。在 Windows 上，这些命令会随 iCode 一起结束。

### 在 TUI 中查看和停止后台命令

主智能体等待 Shell 命令时，命令卡片上会显示“ctrl+t 转到后台”。按 **Ctrl+T** 可以立即把主智能体正在运行的 Shell 命令转到后台。如果会话已有 32 条命令在后台运行，iCode 会提示你，命令照常在前台继续运行。

侧边栏的**任务**标签页上方是待办事项，下方的**后台任务**列出主智能体的后台命令，以及每条命令转到后台后已运行的时长和退出码或状态；状态栏会显示正在运行的后台命令数量。点击一条命令，可以查看它运行的内容、转到后台的原因，以及不断增加的输出。你可以在这里**停止**它，或者复制它的输出或日志文件路径。有命令结束后，框的右下角会出现**清除已结束**，点击它可以把已结束的命令从列表中移除。

开始新会话（包括使用 `/clear`）、切换到其他会话、退出 iCode，或回滚到启动后台命令之前的轮次时，iCode 会先列出将被停止的命令并询问你。选择**停止并继续**（退出时为**停止并退出**）即可继续操作。iCode 询问时如果你再次退出，iCode 会立即退出。直接关闭终端窗口时，后台命令会停止，不会询问。

停止确认框中的每条命令最多显示两行，左对齐。下方同一行左侧显示原因，右侧显示运行时间；空间不足时优先显示原因，隐藏时间。长命令保留开头和结尾，悬停时通过提示框显示完整命令。弹窗随终端尺寸调整，任务较多时只滚动列表，操作影响说明和按钮保持可见；窄窗口中按钮纵向排列。
