# 配置智能体

iCode 使用智能体配置定义智能体的名称、提示词、模型、可调用工具和子智能体等。本指南介绍如何在终端用户界面（Terminal User Interface，TUI）中创建、克隆、修改、重置、切换和删除智能体配置，以及如何为智能体设置模型和子智能体。

## 打开智能体配置窗口

可通过以下任一方式打开“智能体配置”窗口：

- 按 **F2**。
- 点击界面底部的 `f2 智能体`。
- 在输入栏中输入 `/agents`，按空格键或 **Enter** 显示标签页列表，然后选择要打开的标签页。

“智能体配置”窗口左侧显示已有智能体配置列表，右侧通过不同标签页展示当前选中智能体的配置内容。

通过在 `/agents` 后添加标签名，可以直接打开对应标签页：

| 命令 | 打开的标签页 |
| --- | --- |
| `/agents basic` | 基本 |
| `/agents instructions` | 提示词 |
| `/agents tools` | 工具 |
| `/agents sub-agents` | 子智能体 |
| `/agents skills` | Skills |
| `/agents mcp` | MCP |
| `/agents memory` | 记忆 |
| `/agents compaction` | 压缩 |

任务运行期间，“智能体配置”窗口将以只读模式打开，无法修改或保存配置。请等待任务结束后再进行配置调整。

## 管理智能体配置

### 创建智能体配置

以下步骤用于创建“内置”类型的智能体。如需将外部程序接入为子智能体，请参阅[配置外部 ACP 智能体](../extensions/external-acp-agents.md)。

1. 点击“新建”。

2. 在“基本”标签页中配置智能体基本信息：
    - 填写名称、显示名称和描述，三个字段均不能为空。其中，“名称”用于标识智能体配置，“显示名称”显示在智能体选择列表和主界面中。“名称”必须以字母或数字开头，只能包含英文字母、数字、连字符（`-`）和下划线（`_`），且不能与已有名称重复（不区分大小写）。
    - 根据使用场景选择是否勾选“仅用作子智能体”。有关主智能体和子智能体的区别，请参阅[主智能体和子智能体](#主智能体和子智能体)。
    - 根据需要设置智能体使用的模型。默认使用当前活动的模型配置；如需绑定特定模型配置，请参阅[设置智能体使用的模型](#设置智能体使用的模型)。

3. 在“提示词”标签页中填写系统提示词，用于定义智能体的行为准则。系统提示词不能为空。

4. 根据需要在其他标签页中添加智能体配置：
    - **工具**：选择智能体可以调用的内置工具和 [Python 扩展](../extensions/python-extensions.md)。参阅[配置工具](./tools.md)。
    - **子智能体**：添加该智能体可以调用的子智能体。参阅[为智能体配置子智能体](#为智能体配置子智能体)。
    - **Skills**：配置智能体加载 Skill 的位置。参阅[安装和使用 Skills](../extensions/skills.md)。
    - **MCP**：连接 MCP 服务器，并配置智能体可以使用的 MCP 工具。参阅[连接 MCP 服务器](../extensions/mcp.md)。
    - **记忆**：添加需要自动加载到上下文中的文件或文件夹。参阅[配置记忆](./memory.md)。
    - **压缩**：调整对话内容较多时的上下文压缩方式。新建的智能体配置会使用默认的上下文压缩设置，通常无需修改。如需修改，请参阅[配置上下文压缩](./compaction.md)。

5. 点击“保存”。

### 克隆智能体配置

需要基于现有智能体创建新的配置时，可以使用克隆功能。克隆会生成一个独立副本，不会修改原智能体配置。克隆内置智能体时，iCode 会创建对应的自定义智能体副本，后续可以独立修改。

1. 在左侧列表中选择要克隆的智能体。
2. 点击“克隆”。
3. iCode 会复制原智能体的配置，自动生成不重复的智能体名称和显示名称，并选中生成的副本。
4. 检查并按需修改副本的名称、显示名称和其他配置。
5. 点击“保存”完成创建。

**说明：**

- 点击“克隆”后，iCode 会创建一个用于当前配置界面编辑的临时副本，只有点击“保存”后，该配置才会正式创建并保留。
- 修改配置后，需要点击“保存”才能应用修改；关闭智能体配置窗口前未保存的修改内容不会生效。

### 修改智能体配置

1. 在左侧列表中选择需要修改的智能体。
2. 在对应标签页中调整配置。
3. 点击“保存”以应用修改。

**说明：**

- iCode 默认提供的内置智能体（如 Code Agent、Q&A Agent）的“名称”和“智能体类型”不可修改，其他配置可以按需调整。
- 修改配置后，需要点击“保存”才能应用修改；关闭智能体配置窗口前未保存的修改内容不会生效。
- 如果修改的是当前会话正在使用的智能体，保存后，新配置将在后续请求中生效。

### 删除自定义智能体配置

删除自定义智能体后，保存在本机的相关配置也会被移除，且无法在 iCode 中撤销。内置智能体不能删除。

删除自定义智能体前，需要满足以下条件：

- 至少保留一个可用的主智能体。
- 如果该智能体仍被其他智能体配置为子智能体，需要先移除相关引用。

按以下步骤删除自定义智能体：

1. 在左侧列表中选择要删除的自定义智能体。
2. 点击“删除”。
3. 在确认窗口中核对智能体名称，然后确认删除。

如果删除的是当前正在使用的智能体，关闭配置窗口后，iCode 会自动切换到其他可用的主智能体。

### 重置内置智能体配置

iCode 默认提供的内置智能体不支持删除。

修改内置智能体并保存后，iCode 会在[用户智能体配置目录](../../reference/agent-profile.md#用户智能体配置目录)中生成同名的用户配置文件，例如 `Code.yaml`。该文件会保存修改内容以及当时生效的其他设置。例如，只新增一个 MCP 服务器时，保存后的配置既包含这个 MCP 服务器，也保留其他设置当时的值。

启动时，iCode 会优先使用同名的用户配置文件，而不会将用户配置与内置配置逐项合并。因此，升级 iCode 后，新版本对内置智能体提示词等默认设置的更新不会自动应用到该智能体。

如需采用当前版本的内置默认设置，可以重置内置智能体。重置只保留 Skills、MCP 服务器、记忆和[扩展](../extensions/python-extensions.md)设置；提示词、压缩设置及其他设置均恢复为当前版本的内置默认值。

按以下步骤重置：

1. 在左侧列表中选择要重置的内置智能体。
2. 点击“重置”，然后在确认窗口中再次点击“重置”。
3. 如果“保存”按钮可用，点击“保存”应用重置结果。如果该按钮不可用，表示当前配置已经符合上述重置结果，无需保存。

重置产生的修改在保存前只会暂存在设置窗口中。关闭窗口会放弃尚未保存的修改。

重置后，如果不再存在同名的用户配置文件，后续升级会直接采用新版内置配置。如果该文件因保留了自定义的 Skills、MCP 服务器、记忆或扩展设置而继续存在，以后升级时仍需再次重置，才能同步新版的内置默认设置。

## 配置模型和子智能体

### 设置智能体使用的模型

新创建的智能体默认使用当前活动的模型配置，切换当前使用的模型后，智能体使用的模型也会随之切换。

如果希望智能体始终使用特定模型配置：

1. 在左侧列表中选择智能体，然后打开“基本”标签页。
2. 取消勾选“使用当前生效的模型配置”（标签中也会显示当前配置）。
3. 在下拉列表中选择要绑定的模型配置。如需新增或修改模型配置，请参阅[配置模型](./models.md)。
4. 点击“保存”，然后关闭配置窗口。

如果当前使用的主智能体绑定了特定模型配置，状态栏中的模型配置名称将灰度显示。点击它不会切换模型，而是提示该智能体绑定的是哪个模型。

若要重新通过状态栏切换模型，请在该智能体的“基本”标签页中勾选“使用当前生效的模型配置”，点击“保存”，然后关闭配置窗口。

### 主智能体和子智能体

主智能体直接与用户交互，子智能体则由其他智能体调用，负责完成分派的任务。

一项智能体配置既可以作为主智能体，也可以被其他智能体作为子智能体调用。勾选“仅用作子智能体”后，该智能体不能再被选作主智能体，仅可以被其他智能体调用。

iCode 默认提供的 Code Agent 和 Q&A Agent 可以作为主智能体，Explore 和 General 仅用作子智能体。外部 ACP 智能体也仅用作子智能体，配置方法请参阅[配置外部 ACP 智能体](../extensions/external-acp-agents.md)。

### 为智能体配置子智能体

为智能体添加子智能体后，该智能体可以在执行任务时按需调用子智能体完成部分工作。

在智能体配置页面中，按照以下步骤配置子智能体：

1. 在左侧列表中选择需要配置子智能体的智能体。
2. 打开“子智能体”标签页。
3. 点击“+ 添加”，选择要添加的子智能体。
4. 配置子智能体的“工具名称”、“工具描述”和“最大并发数”。
5. 根据需要调整页面顶部的“最大总并发数”。
6. 点击“保存”。

其中：

- “工具名称”和“工具描述”用于帮助智能体识别和使用子智能体。未填写时，分别默认使用子智能体自身的配置名称和描述。
- “最大并发数”用于限制单个子智能体的同时调用数量；“最大总并发数”用于限制所有子智能体的同时调用总数量。

智能体在执行任务时，会根据子智能体的工具名称和工具描述判断是否向其分派任务。也可以在输入框中指定使用某个子智能体，例如：`调用 <工具名称> 完成 <任务>`。对应的子智能体工具成功返回结果，说明配置已经生效。

子智能体将最终回复返回给调用它的智能体。子智能体在工具调用之间输出的文本显示在其卡片中，但不会返回。卡片中的每段文本在子智能体写完后才显示。模型请求失败时，若其文本尚未在卡片中显示，按与主对话相同的规则重试；若已显示部分文本，卡片保留该文本并显示错误。`icode run`、ACP 客户端和工作流不会实时显示子智能体的文本，因此子智能体已输出的文本本身不会阻止上述重试。最终回复无文本时，将子智能体输出的全部文本按顺序拼接后返回。子智能体失败时，其卡片显示失败原因。外部 ACP 智能体返回的内容由其“结果”设置决定，参阅[设置结果和超时](../extensions/external-acp-agents.md#设置结果和超时)。单击卡片上的“查看详情”可查看子智能体执行的全部内容：打开时显示最新内容；停留在底部时，新的工具调用和文本到来会随之显示；向上滚动查看之前的内容时，视图停在原处，直到滚回底部。

**注意**：

- 添加、移除或修改子智能体配置后，必须点击“保存”才能生效。未保存便关闭智能体配置窗口时，本次修改将被丢弃。
- 智能体不能将自身配置为子智能体，也不能在同一配置中重复添加同一个子智能体。

## 切换当前使用的智能体

可以通过输入栏或状态栏切换当前使用的智能体：

- **通过输入栏切换**：在输入栏中输入 `#`，输入栏上方会显示可用的智能体列表。通过鼠标点击，或使用上下方向键选择智能体后按回车确认。
- **通过状态栏切换**：点击输入栏上方状态栏中的智能体名称，打开智能体选择窗口，然后选择要使用的智能体。

切换后，iCode 会立即使用所选智能体处理后续请求。当前使用的智能体在列表中以灰色显示，名称前带有空心圆圈。列表仅显示可以作为主智能体使用的配置。
