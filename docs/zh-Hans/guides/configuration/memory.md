# 配置记忆

本指南介绍如何为主智能体配置记忆。

## 准备记忆内容

**记忆会在主智能体加载时加入系统提示词。** iCode 会读取当前主智能体配置的记忆文件，并将内容作为参考资料提供给智能体。记忆内容会占用模型的上下文窗口，并随请求发送给模型服务。因此，建议避免在记忆中包含密钥、访问令牌等敏感信息。

**子智能体不加载记忆。** 子智能体不会继承主智能体已加载的记忆，也不会加载自身智能体配置中的记忆。[工作流](../running/workflows.md)中的智能体节点则会加载其智能体配置中的记忆。

**记忆适合保存稳定且通用的信息。** iCode 只加载扩展名为 `.md` 或 `.txt` 的记忆文件。适合放入记忆的内容应当能够在多个任务中重复使用，例如项目约定、背景资料和常用信息。内容应简短、明确并保持更新；临时任务要求更适合直接写在当前请求中。

**默认智能体已配置 AGENTS.md 作为记忆。** iCode 默认提供的主智能体（如 Code Agent）会加载工作目录中的 `AGENTS.md`。需要为项目补充通用说明时，可以优先维护该文件；如不需要，可在“记忆”标签页中删除该条目。

## 添加记忆文件

1. 在输入栏中输入 `/agents memory`，打开当前智能体的“记忆”标签页。如需配置其他主智能体，在左侧列表中选择。
2. 在“文件”区域点击“+ 添加文件”。
3. 输入路径，或通过“浏览”按钮选择 `.md` 或 `.txt` 文件。勾选“工作区相对路径”时填写相对路径（例如 `AGENTS.md`、`docs/context.md`），否则填写绝对路径。
   
    > **注意**：相对路径在加载记忆时按当前工作目录解析，而不是按照创建智能体配置时的目录解析。因此，同一个智能体可以在不同项目中加载各自的 `AGENTS.md`。相对路径不能指向工作目录以外的位置；如需加载工作目录以外的文件，请使用绝对路径。
4. 点击“保存”，然后关闭智能体配置窗口。

## 添加记忆文件夹

需要加载一组参考文件时，在“文件夹”区域点击“+ 添加文件夹”，勾选“工作区相对路径”时填写相对路径，否则填写绝对路径。添加完成后点击“保存”，然后关闭智能体配置窗口。

iCode 会先加载该目录直属的 `.md` 和 `.txt` 文件，再逐层扫描子目录。对于每个配置的文件夹，最多扫描两层子目录，最多加载 100 个文件。若某个重要文件可能不在扫描范围内，可将其单独添加到“文件”区域。

## 记忆的加载与重新加载

同一实际文件同时被单独添加和从文件夹中发现时，只会加载一次。多个记忆来源的合计内容上限为 35,000 词元。iCode 先加载单独添加的文件，再加载文件夹；一旦某个文件会使内容超过上限，该文件及其后的所有文件都会被跳过，iCode 会显示警告。

切换工作目录或修改当前智能体配置后，iCode 会根据新路径重新加载记忆。

在磁盘上修改记忆文件后，空闲时执行 `/reload`，下一次请求就会包含新正文。使用 OpenAI Responses 服务端存储时，记忆变化可能使原服务端续接失效；iCode 会提示并从本地历史继续。

## 验证记忆是否加载

在输入栏中输入 `/runtime`，或点击输入栏上方状态栏右端显示的文件数量，打开“运行时详情”窗口，切换到“文件”标签页。页面会按配置来源列出实际加载的文件。预期文件出现在列表中，即表示记忆已加载。

如果预期文件未显示，请检查：

* 路径是否存在，文件扩展名是否为 `.md` 或 `.txt`。
* 相对路径指向的文件是否位于当前工作目录内。
* 添加的条目类型与实际路径是否匹配（文件条目应指向文件，文件夹条目应指向文件夹）。
* 是否出现内容超过 35,000 词元或部分文件被跳过的警告。
* 修改配置后是否点击了“保存”。
