# 配置模型

模型配置包含连接模型服务所需的信息。本指南介绍如何在终端用户界面（Terminal User Interface，TUI）中创建、克隆、修改、切换和删除模型配置。配置保存后，可以在不同任务之间切换，不必重复填写连接参数。

## 打开模型配置窗口

使用以下任一方式打开“模型配置”窗口：

- 按 **F4**。
- 点击界面底部的 `f4 模型`。
- 在输入栏中输入 `/models`。

左侧列表显示已有模型配置，右侧表单显示当前选中配置的内容。

任务运行期间，“模型配置”窗口将以只读模式打开，无法新建、修改或删除配置。请等待任务结束后再进行配置调整。

## 管理模型配置

### 创建模型配置

1. 点击“新建”。
2. 填写自定义的配置名称，例如 `我的模型`。
3. 在模型选项区域，选择模型提供商和 API 样式。仅 OpenAI 和 DeepSeek（OpenAI）提供 API 样式选项。配置前，请根据模型服务商的文档确认其支持的 API，并按文档建议选择 `Chat Completions` 或 `Responses`。如果服务商仅支持其中一种 API，请选择对应的 API 样式；如果两种 API 均支持，则根据服务商的建议或实际使用需求选择。
4. 填写模型 ID，并根据模型服务的要求填写服务地址和 API 密钥。
5. 根据模型提供商的说明，填写最大上下文窗口和最大输出词元数。
6. 根据需要调整流式输出、视觉模型和连接选项。新建的配置默认开启流式输出。
7. 点击“保存”。

**注意事项：**

- 点击“新建”时，iCode 会立即创建并保存一项空白配置。后续填写或修改的内容需要点击“保存”才会生效；直接关闭窗口不会删除已经创建的空白配置。
- 配置名称用于在界面中展示和区分模型配置，不会发送给模型服务。配置名称不能为空，且不能与已有配置重复（不区分大小写）。可以使用中文、空格、字母、数字和常见符号。
- 模型 ID 和词元限制等必填信息不完整时，该配置不会出现在可选模型列表中。
- 开启流式输出后，回复会随模型生成逐步显示。只要模型服务持续发送内容，较长的回复可以超过“HTTP 读取超时（秒）”设定的时长；只有服务停止发送达到该时长时才会超时。在旧版 iCode 中保存时未勾选“流式输出”的配置，现在也会使用流式输出；如需关闭，请取消勾选“流式输出”后再次保存。如果换回旧版 iCode，旧版会把本版本开启流式输出后保存的配置当作未开启。
- 开启视觉模型后，图片会以 PNG、JPEG、GIF 或 WebP 格式发送给模型。工具返回的其他格式图片会改为发送一条“图片已略去”的简短说明，对话可以继续。
- 若此前没有可用的模型配置，新配置在保存并关闭窗口后将自动成为当前使用的模型配置。已有其他模型配置正在使用时，保存新配置不会自动切换模型。
- 如需设置推理强度、提示词缓存或其他请求字段，请使用“其他选项”区域中的“Chat 选项（额外请求字段）”。参见 [Chat 选项](./chat-options.md)，其中还列出了常见模型服务的设置。某次保存让配置成为通过 Anthropic 协议使用的 Claude 配置时，如果缺少缓存设置，iCode 会提示添加。

### 通过环境变量提供 API 密钥

直接填写的 API 密钥会随模型配置文件保存在本机。

若要从环境变量读取密钥，在 API 密钥字段中填写：

```text
{{PROVIDER_API_KEY}}
```

将 `PROVIDER_API_KEY` 替换为存放密钥的环境变量名；启动 iCode 前应确保该环境变量已经设置。环境变量名只能包含字母、数字和下划线，且不能以数字开头。

### 克隆模型配置

需要创建一套大部分参数相同的配置时，可以克隆现有配置。例如，同一提供商下使用不同模型 ID，或为相同模型设置不同的上下文和输出限制。

1. 在左侧列表中选择要复制的模型配置。
2. 点击“克隆”。
3. iCode 会创建并选中一个包含原配置全部字段的副本，并为副本生成不重复的名称。
4. 修改配置名称以及需要变更的字段。
5. 点击“保存”。

克隆操作会在点击“克隆”时立即保存副本，但不会将副本切换为当前使用的模型。

### 修改模型配置

1. 在左侧列表中选择模型配置。
2. 修改需要调整的字段。
3. 点击“保存”。

如果修改了正在使用的模型配置，保存并关闭配置窗口后，新配置将用于后续请求。

### Claude 思考设置

Claude Opus 5.5、Fable 5.1 和 Sonnet 5.5 会把返回的思考内容与它之前的对话绑定。之前的对话发生变化后（例如 iCode 压缩了上下文），模型服务可能拒绝读回这些思考内容。当这些模型在 Anthropic 官方地址上使用自适应思考（在 [“Chat 选项”](./chat-options.md#anthropic)中设置 `"thinking": {"type": "adaptive"}`）时，iCode 会请服务略去对不上的思考内容，而不是拒绝请求。这样模型看到的早先推理会变少，但请求可以正常完成。对于服务原本不做这项检查的账号，这项要求也会让服务开始检查，对不上的思考内容同样会被略去。

如需更改，请在 iCode 配置目录的 `models` 文件夹中（macOS 和 Linux 为 `~/.chrys/models/`，Windows 为 `%APPDATA%\chrys\models\`；文件中的 `name:` 一行即配置名称）打开该配置的文件，添加一行 `thinking_block_binding`，取下列值之一，然后重启 iCode：

| 值 | iCode 向服务提出的要求 |
| --- | --- |
| `auto`（默认） | 如上所述。 |
| `drop_block` | 略去对不上的思考内容。适用于任何地址和模型，只要思考为自适应或固定预算。 |
| `error` | 遇到对不上的思考内容时拒绝请求。适用于任何地址和模型，只要思考为自适应或固定预算。 |
| `off` | 不提出要求。你在“Chat 选项”的 `thinking` 中自己写的 `block_binding` 仍会原样发送。 |

如果服务仍因对不上的思考内容拒绝了请求，iCode 会去掉读回的早先思考内容，再发送一次请求，之后也不再发送这些思考内容。这会多发一次请求，模型也不再看到那部分早先的推理。设为 `error` 时，iCode 会直接报告这次拒绝。

在 Anthropic 官方地址上使用固定预算的思考（`"type": "enabled"`）时，iCode 还会开启工具调用之间的思考。Claude Haiku 4.5 和 Claude Opus 4.6 在这种模式下不支持，因此不会开启。如需关闭，请添加一行 `auto_interleaved_thinking: false`。

之后在“模型配置”窗口中保存该配置时，这些行会保留。

### 删除模型配置

删除操作会移除保存在本机的模型配置文件，且**无法在 iCode 中撤销**。确认不再需要该配置后：

1. 打开“模型配置”窗口。
2. 在左侧列表中选择要删除的配置。
3. 点击“删除”。
4. 在确认窗口中再次核对要删除的配置名称，然后点击“删除”。

iCode 至少保留一项模型配置，因此只剩一项时无法点击“删除”。如果删除了正在使用的配置，关闭配置窗口后，iCode 会自动切换到其他可选配置。

## 切换和验证模型配置

### 切换当前模型配置

可以点击模型配置名称标签，或在输入栏中快速切换模型配置。

点击模型配置名称标签：

1. 点击输入栏上方状态栏中的模型配置名称，打开模型选择窗口。
2. 通过鼠标点击，或使用上下方向键选择模型配置后按回车确认。

在输入栏中快速切换：

1. 在输入栏中输入 `$`，模型配置列表会显示在输入栏上方。
2. 继续输入配置名称以筛选结果。
3. 使用上下方向键选择模型配置，然后按回车确认。

切换后，状态栏会显示新的模型配置名称。当前使用的配置在列表中以灰色显示，名称前带有空心圆圈。缺少必填项的模型配置不会显示在列表中。

当前对话会在新的模型配置下继续。有些模型服务返回的推理内容只有它自己能读取，例如 Claude 的思考内容和 OpenAI 的加密推理。如果新配置把请求发往另一个服务地址，iCode 会在请求中略去这些早先的推理内容。你的消息、模型的回复以及 iCode 运行的工具结果仍会照常发送；同一步中由模型服务自己运行的工具，其结果也可能被略去。切换回使用原地址的配置后，这些推理内容会重新发送。早期 iCode 版本保存的推理内容仍按原来的方式发送。

如果状态栏中的模型配置名称灰度显示，表示当前智能体已绑定特定模型配置，点击它只会提示绑定情况。此时输入 `$` 也不会显示模型配置列表，需要先[修改该智能体的模型设置](./agents.md#设置智能体使用的模型)，才能切换模型配置。智能体正在运行时也不能切换。

### 验证模型配置

切换模型后，在输入栏中提交：

```text
你好
```

iCode 应正常返回问候回复。若模型服务返回错误，先核对模型 ID、服务地址、API 密钥等模型配置。

仍报错时，对照以下现象排查：

- **报错信息包含 `The Chat Completions client supports only n=1`**：使用 Chat Completions 样式时，iCode 每次请求只处理一条回复，不支持多候选回复，`n` 参数应省略或设为整数 `1`。在模型配置的[“Chat 选项（额外请求字段）”](./chat-options.md)中把该值删除或改为 `1`，包括经 `extra_body` 间接设置的情况。
- **返回状态为 `HTTP 200` 但响应不是有效的模型回复**：例如 Content-Type 为 `text/html`，正文是错误页或空内容。出现这种情况说明网关或代理把后端错误包装成了成功响应；此时核对所选 API 样式与模型服务地址是否匹配，并检查代理路由。
- **使用 Chat Completions 样式时，报错信息以 `Error code: 200` 开头**：模型服务或网关在成功响应中报告了错误。iCode 会显示服务给出的错误内容。再次尝试可能成功的错误（例如服务繁忙）会重试；再次尝试仍会遇到的错误（例如 API 密钥无效、额度用尽或请求被拒绝）不会重试。
- **使用 Chat Completions 样式时，报错为 `Response contained a tool call without a function name.`**：模型请求调用工具，却没有给出工具名称。iCode 不会执行这条回复中的任何内容，而是重新请求模型；只有下一条回复仍是这样时才会出现此报错。请重新发送消息，或换用其他模型。
- **模型服务的内容过滤拦截了回复**：iCode 不会重试该请求，也不会执行被过滤或被拒绝的回复中请求的工具。请换一种方式描述需求。
- **使用 Responses 样式时，模型服务报告回复失败**：iCode 会显示服务给出的错误。只有再次尝试可能成功的错误（例如服务器错误或限流）才会重试；服务拒绝的请求（例如含有无法读取的图片，或超出账户额度）不会重试。流式回复在完成前中断时，也按同样的规则重试。超出上下文窗口的请求例外，参见[无法连接模型服务时](#无法连接模型服务时)。如果服务在这次失败的回复中已经执行过可能产生改动的工具（例如 MCP 调用），iCode 不会重试，以免工具重复执行。如果服务始终不说明流式回复是否已完成，iCode 会保留已收到的内容，并在日志中记录一条警告。
- **使用 Anthropic 协议时，流式回复在完成前中断**：iCode 会重试该请求，且不会执行中断的回复中请求的工具。与 Responses 样式一样，如果服务已经执行过可能产生改动的工具（例如 MCP 调用），iCode 不会重试，以免工具重复执行。
- **流式回复有时中途停止，但没有报错**：部分使用 Chat Completions 样式的服务在结束流式输出时不说明回复是否已完成，iCode 会保留这样的回复。如果希望 iCode 把它当作中断的回复并重试，请在 iCode 配置目录的 `models` 文件夹中（macOS 和 Linux 为 `~/.chrys/models/`，Windows 为 `%APPDATA%\chrys\models\`；文件中的 `name:` 一行即配置名称）打开该配置的文件，添加一行 `stream_requires_finish_reason: true`，然后重启 iCode。之后在“模型配置”窗口中保存该配置时，这一行会保留。
- **开启流式输出后请求失败，且模型服务或网关不支持流式输出**：在模型配置中取消勾选“流式输出”并保存。如果直接修改配置文件，请添加一行 `stream: false`，然后重启 iCode。关闭流式输出只能解决服务不支持流式输出导致的问题。

### 无法连接模型服务时

iCode 能判断模型请求失败的原因时，会用通俗的话说明原因，并在下方附上原始错误信息；暂停的子智能体卡片上也是如此。iCode 自动重试时，重试提示只显示这句说明。如果运行 iCode 的设备看起来没有网络连接，iCode 也会一并提示，此时请先检查网络。

| 提示内容 | 检查什么 |
| --- | --- |
| 无法解析服务地址 | 网络连接和 DNS 设置。如果地址填错了，在模型配置中修改服务地址。 |
| 拒绝了连接 | 服务地址中的地址和端口，以及模型服务是否正在运行。 |
| 连接超时或等待响应超时 | 网络、防火墙或 VPN。 |
| 无法连接到代理 | 代理软件是否正在运行、代理设置是否正确。如需不经代理直接连接，在模型配置中开启“绕过代理”。 |
| 代理要求身份验证 | 代理的用户名和密码。 |
| 无法建立安全连接 | 在公司网络中，检查代理的证书设置。 |
| API 密钥无效或没有访问权限 | 模型配置中的 API 密钥。 |
| 请求超出模型的上下文窗口 | 模型配置中的上下文窗口是否与模型的实际值一致。开启上下文压缩时，iCode 会压缩上下文并重新发送一次请求，只有这次也失败时才会显示该错误。参见[配置上下文压缩](./compaction.md)。 |
| 模型配置的最大上下文窗口大于服务端支持的上限 | 在模型配置中把“最大上下文窗口”改为提示中给出的服务端上限或更小，并保存。 |
