# 工作目录

工作目录是 iCode 执行文件操作和命令时使用的默认目录。在让智能体修改文件前，建议先保存尚未写入磁盘的内容，并使用 Git commit 记录已有变更，以便区分智能体所做的修改，并在需要时恢复到修改前的状态。

## 启动时选择工作目录

在终端中进入工作目录并启动 iCode：

```shell
cd <working-directory>
icode
```

iCode 会将启动时所在的目录作为工作目录。

也可以通过 `-C` 或 `--workdir` 选项指定工作目录，无需先进入工作目录：

```shell
icode -C <working-directory>
```

## 在会话中切换工作目录

智能体空闲时，可以点击对话区底部边框右侧显示的当前工作目录路径，或在输入栏中输入 `/chdir`，打开“更改目录”窗口。在窗口中浏览并选择目标目录。如需新建文件夹，先点击要放置它的文件夹，再点击“新建文件夹”，输入名称后按 Enter，新文件夹会被自动选中。若目标工作目录最近使用过，可在“收藏”标签页的“最近”分组中选择。

已知目标路径时，在输入栏中输入以下命令可直接切换：

```text
/chdir <working-directory>
```

`<working-directory>` 可以是绝对路径，也可以是相对于当前工作目录的路径。如果目标不存在或不是目录，iCode 会提示错误并保留当前工作目录。

切换完成后，对话区底部边框右侧会显示新的工作目录路径。智能体后续的文件读取、命令和其他操作会以新工作目录作为默认位置。

切换工作目录时，iCode 会重新加载当前智能体，并加载新工作目录中的记忆和 Skills（其中的 Skills 仅在勾选“加载工作目录 Skills”时加载）。具体配置方式参阅[配置记忆](../configuration/memory.md)和[安装和使用 Skills](../extensions/skills.md)。

在“未指定”会话中切换工作目录会保留当前对话及其历史。处理无关项目时，建议先输入 `/new` 创建新会话，再在新会话中切换工作目录，避免在原会话中留下工作目录变更记录或混用不同项目的上下文。

## 工作区

工作区以一个名称把一个主文件夹和若干参考文件夹组织在一起。会话要么属于某个工作区，要么是“未指定”：“未指定”的会话只使用自己的工作目录，与以往一样。

1. 点击底部状态栏的工作区标签，打开选择器。也可以输入 `/workspace switch`，如果补全列表已打开，先按 Esc 关掉它，再按 Enter。
2. 选择 **新建工作区…**，输入名称并选定主文件夹。需要时用 **添加文件夹…** 加入参考文件夹。
3. 点击 **创建**。iCode 保存工作区。会话已有消息时，可以选择移动会话、在新工作区打开新会话，或取消切换。

选定文件夹后会返回工作区表单。参考文件夹可用，且与主文件夹和已有参考文件夹均不相同、互不包含时，才会添加到列表。创建或保存时，iCode 会检查名称是否已被使用，或是否已有工作区使用完全相同的主文件夹和参考文件夹。如有重复，表单会保留草稿，方便修改名称或文件夹。

保存失败时，表单会显示原因并保留草稿，方便重试。

工作区按“包含当前目录优先，其次最近使用”排序，选择器和命令补全使用相同顺序。打开选择器时，会高亮当前工作区或 **未指定**。在选择器中选择工作区，或输入 `/workspace switch <名称>` 直接切换。选择 **未指定** 或输入 `/workspace switch 未指定`，可在当前工作目录切换到未指定。已有消息时，可选择 **移动这个会话**、**新会话**或**取消**。选择 **新会话** 会保留原会话，并在所选项下打开新会话。再次选择当前项会关闭选择器。目标工作区的主文件夹不存在时，iCode 会提示工作区名称和文件夹路径。

用选择器行尾的 **编辑** 修改名称和参考文件夹，即使主文件夹不存在也可编辑。选择器会用主题警告色标注缺失的主文件夹，编辑对话框和状态栏悬停提示会标注所列出的缺失文件夹。恢复主文件夹后即可进入工作区。如需更换主文件夹，请新建工作区。点击 **✕** 可移除参考文件夹。

用选择器行尾的 **删除** 移除工作区。文件夹和会话都会保留，原来属于该工作区的会话会显示为“未指定”。即使主文件夹已缺失，也可以删除当前工作区。当前会话保留原工作目录；该目录已缺失时，下次发消息会请你选择替代文件夹。

如果编辑期间有人在别处修改或删除了同一个工作区，表单会保留草稿。你可以在关闭前复制草稿。工作区仍存在时，可重新打开编辑窗口修改。

底部状态栏显示当前工作区，或显示“未指定”。终端较窄时，状态栏会缩短工作区、智能体和模型的名称，空间更少时也会隐藏相应的标签。

主文件夹可用且工作区有参考文件夹时，选择器会在主文件夹路径旁显示参考文件夹的数量。状态栏悬停提示会标明主文件夹并列出参考文件夹，超出显示范围时会注明还有几个参考文件夹。

如需在工作区中启动，使用 `--workspace` 指定工作区的名称或 ID。`icode run` 也支持该选项。它不能与 `-C` 同时使用。

```shell
icode --workspace <workspace-name>
```

无需打开会话，也可以在命令行管理工作区。`new` 使用当前目录作为主文件夹。`<workspace>` 与 `--workspace` 使用相同的选择规则：完整 ID、不区分大小写的名称，或唯一的 ID 前缀。已打开的会话会在下次打开时看到这些变更。

```shell
icode workspace list
icode workspace list --json
icode workspace new <name>
icode workspace rename <workspace> <new-name>
icode workspace add-folder <workspace> <path>
icode workspace remove-folder <workspace> <path>
icode workspace delete <workspace>
```

iCode 会在工作区的主文件夹中打开会话，智能体也可以在其参考文件夹中工作。如果 iCode 找不到或无法访问参考文件夹，打开工作区时会跳过这些文件夹，并在一条提示中列出路径。可以恢复访问后重新打开会话，或把它们从工作区中移除。

`/new`、`/clear` 和分叉会让会话留在原工作区。用 `/chdir` 或“更改目录”离开主文件夹时，iCode 总会先确认，并提示当前会话能否在不切换工作目录的情况下使用目标文件夹。移动会话会将它设为“未指定”。如果会话已有消息，也可在目标文件夹打开一个“未指定”的新会话，让原会话留在工作区。

恢复工作区中的会话时，如果主文件夹已不存在，iCode 会请你选择一个替代文件夹，会话将以“未指定”的状态在那里继续。如果是通过 `--workspace` 启动 iCode，则会提示主文件夹不存在并退出。

工作区中的文件夹链接改指后，请重新打开该工作区以使用新的目标。

如果工作区列表由更高版本的 iCode 保存，当前版本会显示提示，并且不会保存对工作区的更改。

### 在终端和编辑器中使用工作区命令

在终端中，输入 `/workspace` 后按空格可查看动作和名称补全，当前工作区用 **◦** 标出。Enter 如何处理高亮的补全项，见[斜杠命令](../../reference/tui-slash-commands.md)。

| 命令 | 效果 |
| --- | --- |
| `/workspace` | 显示用法和可用动作。 |
| `/workspace switch` | 在终端打开选择器。在支持 ACP 的编辑器中列出工作区名称、主文件夹和未指定项。 |
| `/workspace switch <名称>` | 切换到指定工作区。在支持 ACP 的编辑器中，目标工作区的主文件夹须为当前目录，再次选择当前工作区时会提示当前会话已在该工作区中。 |
| `/workspace switch Unspecified` | 切换到未指定，保留当前工作目录。中文终端也接受 `/workspace switch 未指定`。 |
| `/workspace new <名称>` | 以当前目录为主文件夹创建工作区。进入工作区后，可以用 `/workspace add-folder <路径>` 添加参考文件夹。 |
| `/workspace rename <新名称>` | 重命名当前工作区。 |
| `/workspace add-folder <路径>` | 为当前工作区添加参考文件夹。 |
| `/workspace remove-folder <路径>` | 从当前工作区移除参考文件夹。 |
| `/workspace delete <名称>` | 直接删除指定工作区，保留文件夹和会话。 |

**Unspecified** 及其各语言显示名（如 **未指定**）是保留名称。如果已有工作区使用了这些名称，请用 `icode workspace list --json` 查到完整 ID，再执行 `icode workspace rename <ID> <新名称>` 改名。工作区名称不能重复（不区分大小写）；如果手动编辑的工作区列表里有重名，iCode 无法读取该列表，需要先在文件里把其中一个改名。

在支持 ACP 的编辑器中，如果要切换到主文件夹不同的工作区，请打开目标文件夹，新建对话后执行 `/workspace switch <名称>`。使用 ACP 的编辑器会把当前会话移入新建的工作区。在终端里，如果会话已有消息，可以选择移动会话、打开新会话或取消切换。取消后，可随时从工作区选择器进入刚创建的工作区。

支持 ACP 的编辑器传入的附加目录在新建或加载会话时生效。重新打开仍在运行的会话会沿用当前的文件夹。加载已关闭的会话时，如果编辑器没有传入附加目录，工作区会话使用工作区定义，未指定的会话恢复已保存的文件夹。切换到未指定时只保留当前文件夹。

名称和路径有空格时直接输入，无需加引号。相对路径以当前会话的工作目录为起点。也可以输入绝对路径，或用 `~` 代表主目录。查找工作区时不区分大小写。会话位于工作区的主文件夹时，编辑立即生效。会话使用其他文件夹时，改动在下次打开该会话时生效。要更换主文件夹，请新建工作区。

## 工作目录被删除或移动时

如果在 iCode 之外（例如在文件管理器或另一个终端中）删除或移动了工作目录，iCode 将无法继续使用它：

- 正在执行的任务会继续运行。需要使用工作目录的命令和文件操作会失败，智能体会告诉你该目录已不存在。
- 任务结束时，或你发送消息时，iCode 会弹出“工作文件夹不存在”窗口。点击“选择文件夹…”并选择一个文件夹，“更改目录”窗口会定位到仍然存在的最近一级文件夹。iCode 会切换到所选文件夹，并保留当前对话。
- 你发送的消息会保留在输入栏中，切换后再次发送即可。
- 如果关闭窗口而未选择文件夹，下次发送消息时窗口会再次弹出。也可以使用 `/chdir` 切换，或将文件夹移回原来的位置。

恢复的会话所保存的工作目录已不存在时，iCode 会请你选择一个文件夹来打开该会话。如果是通过 `-s` 启动 iCode，取消选择文件夹后可以重试，也可以选择“开始新会话”。

如果 iCode 已关闭原会话，而要恢复的会话未能加载智能体，可以切换目录或切换模型来开始新对话，也可以重新打开已保存的会话。新对话为“未指定”，在原目录中开始；原目录已不存在时则使用启动目录。

在另一个文件夹中恢复当前会话时，正在运行的后台命令会保留在任务列表中，关闭该会话或退出 iCode 时才会停止。

如果在已不存在的目录中启动 iCode，iCode 会提示错误并退出。请进入一个存在的目录，或使用 `-C` 指定工作目录的完整路径，例如 `icode -C ~/code/my-app`。
