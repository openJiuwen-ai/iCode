# 工作目录

工作目录是 iCode 执行文件操作和命令时使用的默认目录。在让智能体修改文件前，建议先保存尚未写入磁盘的内容，并使用 Git commit 记录已有变更，以便区分智能体所做的修改，并在需要时恢复到修改前的状态。

## 启动时选择工作目录

在终端中进入工作目录并启动 iCode：

```shell
cd <working-directory>
icode
```

iCode 会将启动时所在的目录作为工作目录。

也可以通过 `-C` 或 `--workdir` 选项指定工作目录，无需先进入工作目录：

```shell
icode -C <working-directory>
```

## 在会话中切换工作目录

智能体空闲时，可以点击对话区底部边框右侧显示的当前工作目录路径，或在输入栏中输入 `/chdir`，打开“更改目录”窗口。在窗口中浏览并选择目标目录。如需新建文件夹，先点击要放置它的文件夹，再点击“新建文件夹”，输入名称后按 Enter，新文件夹会被自动选中。若目标工作目录最近使用过，可在“收藏”标签页的“最近”分组中选择。

已知目标路径时，在输入栏中输入以下命令可直接切换：

```text
/chdir <working-directory>
```

`<working-directory>` 可以是绝对路径，也可以是相对于当前工作目录的路径。如果目标不存在或不是目录，iCode 会提示错误并保留当前工作目录。

切换完成后，对话区底部边框右侧会显示新的工作目录路径。智能体后续的文件读取、命令和其他操作会以新工作目录作为默认位置。

切换工作目录时，iCode 会重新加载当前智能体，并加载新工作目录中的记忆和 Skills（其中的 Skills 仅在勾选“加载工作目录 Skills”时加载）。具体配置方式参阅[配置记忆](../configuration/memory.md)和[安装和使用 Skills](../extensions/skills.md)。

切换工作目录不会创建新会话，当前对话历史仍会保留。处理无关项目时，建议先输入 `/new` 创建新会话，再在新会话中切换工作目录，避免在原会话中留下工作目录变更记录或混用不同项目的上下文。

## 工作区

工作区以一个名称把一个主文件夹和若干参考文件夹组织在一起。会话要么属于某个工作区，要么是“未指定”：“未指定”的会话只使用自己的工作目录，与以往一样。本版本可以打开已登记的工作区，创建和管理工作区将在后续版本提供。

如需在工作区中启动，使用 `--workspace` 指定工作区的名称或 ID。`icode run` 也支持该选项。它不能与 `-C` 同时使用。

```shell
icode --workspace <workspace-name>
```

iCode 会在工作区的主文件夹中打开会话，智能体也可以在其参考文件夹中工作。打开工作区时不存在的参考文件夹会被略过。

`/new`、`/clear` 和分叉会让会话留在原工作区。用 `/chdir` 切换到其他任何文件夹（包括参考文件夹）会离开工作区。如果会话中已有消息，iCode 会询问是把当前会话移到新文件夹，还是在新文件夹中新建会话。

恢复工作区中的会话时，如果主文件夹已不存在，iCode 会请你选择一个替代文件夹，会话将以“未指定”的状态在那里继续。如果是通过 `--workspace` 启动 iCode，则会提示主文件夹不存在并退出。

工作区中的文件夹链接改指后，请重新打开该工作区以使用新的目标。

如果工作区列表由更高版本的 iCode 保存，当前版本会显示提示，并且不会保存对工作区的更改。

## 工作目录被删除或移动时

如果在 iCode 之外（例如在文件管理器或另一个终端中）删除或移动了工作目录，iCode 将无法继续使用它：

- 正在执行的任务会继续运行。需要使用工作目录的命令和文件操作会失败，智能体会告诉你该目录已不存在。
- 任务结束时，或你发送消息时，iCode 会弹出“工作文件夹不存在”窗口。点击“选择文件夹…”并选择一个文件夹，“更改目录”窗口会定位到仍然存在的最近一级文件夹。iCode 会切换到所选文件夹，并保留当前对话。
- 你发送的消息会保留在输入栏中，切换后再次发送即可。
- 如果关闭窗口而未选择文件夹，下次发送消息时窗口会再次弹出。也可以使用 `/chdir` 切换，或将文件夹移回原来的位置。

恢复的会话所保存的工作目录已不存在时，iCode 会请你选择一个文件夹来打开该会话。如果是通过 `-s` 启动 iCode，取消选择文件夹后可以重试，也可以选择“开始新会话”。

如果 iCode 已关闭原会话，而要恢复的会话未能加载智能体，可以切换目录或切换模型来开始新对话，也可以重新打开已保存的会话。新对话为“未指定”，在原目录中开始；原目录已不存在时则使用启动目录。

在另一个文件夹中恢复当前会话时，正在运行的后台命令会保留在任务列表中，关闭该会话或退出 iCode 时才会停止。

如果在已不存在的目录中启动 iCode，iCode 会提示错误并退出。请进入一个存在的目录，或使用 `-C` 指定工作目录的完整路径，例如 `icode -C ~/code/my-app`。
