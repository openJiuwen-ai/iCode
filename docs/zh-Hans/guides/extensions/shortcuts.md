# 编写和使用快捷指令

快捷指令是保存为 Markdown 文件的提示词：写好一次，以后输入 `/` 和名称即可复用。选中后，提示词会填入输入栏，修改后再发送。快捷指令还可以接收参数、为本会话切换智能体或模型，并在发送时填入 shell 命令的输出。快捷指令在 iCode 界面中使用；`icode run` 和通过 `icode acp` 连接的编辑器会把 `/名称` 当作普通文本发送。

## 快捷指令文件放在哪里

iCode 从以下两处读取快捷指令：

| 目录 | macOS 和 Linux | Windows |
| --- | --- | --- |
| 你自己的快捷指令 | `~/.chrys/shortcuts` | `%APPDATA%\chrys\shortcuts` |
| 项目的快捷指令 | 工作目录及其上级目录（直到仓库根目录）中的 `.chrys/shortcuts` | 同左 |

新增或修改的文件，下次输入 `/` 时即可看到。

项目的 `.chrys/shortcuts` 必须位于仓库内：如果它是指向仓库外目录的链接，iCode 会跳过它。

文件名就是快捷指令的名称：`review.md` 对应 `/review`。子目录中的文件名称带上目录：`git/commit-msg.md` 对应 `/git/commit-msg`。不同目录中有同名快捷指令时，使用最先读到的那个，顺序为：你自己的快捷指令、最近的项目目录。

以下文件不会加载：名称含空格的文件（无法在 `/` 后输入）、名称以 `.` 开头的文件或目录，以及链接形式的子目录。找不到某个快捷指令时，先检查它的文件名。

要查看已加载哪些快捷指令及其来源目录，输入 `/runtime` 并打开“快捷指令”标签页。

## 编写快捷指令

快捷指令文件是 Markdown 文件，开头可以在两行 `---` 之间写设置：

```text
---
description: 审查我未提交的改动
agent: QA
model: my-provider/my-model
---

审查以下改动，先指出缺陷：

!`git diff --stat`

重点关注 $ARGUMENTS。
```

| 设置 | 作用 |
| --- | --- |
| `description` | 在 `/` 列表中显示在名称后面。 |
| `agent` | 发送时切换到的智能体。 |
| `model` | 发送时切换到的模型：模型配置的名称，或 `provider/model`。 |

设置之后的全部内容就是提示词。

提示词中可以使用：

- `$ARGUMENTS`：名称后输入的全部内容。
- `$1`、`$2`…：按空格拆分的单个参数；含空格的参数用引号括起来（`"会议改到下午"`）。编号最大的那个会接收剩余的全部参数。
- 不含任何占位符：名称后输入的内容会空一行后追加到提示词末尾。
- `` !`命令` ``：发送时在会话的工作目录中运行该命令，并用它的输出替换这一处。

## 使用快捷指令

1. 在输入栏输入 `/`，快捷指令列在“快捷指令”分组中。
2. 选中一个，或输入名称（可带参数，如 `/review 错误处理`）后按 **Tab** 或 **Enter**。
3. 提示词会填入输入栏。没有给出的参数会高亮显示：按 **Tab** 在它们之间跳转，直接输入即可填写。仍有空位时按 **Enter**，iCode 会先提醒一次再发送。用 **↑** 翻看提示词历史再用 **↓** 回来，提示词会原样回来，高亮也保留；在全屏编辑器中未改动文本就关闭时同样如此。如果在编辑器中改动了文本，高亮会去掉，但提示词仍属于这个快捷指令。
4. 按需修改提示词，然后按 **Enter** 发送。

### 提示词中的命令

发送时，先由你的[提示词钩子](hooks.md)检查提示词，检查的是你输入的原文，包括其中的命令。之后，其中每个 `` !`命令` `` 在会话的工作目录中运行，模型收到的消息里用它的输出替换这一处；对话中显示的也是替换后的消息。每条命令最多运行 10 秒，输出最多保留 16 KB。命令运行期间，状态栏会显示正在运行，切换智能体、新建会话等操作要等它结束；按 **Esc** 可以取消。钩子拦下提示词、命令无法启动、超时、被取消，或因其他原因无法发送时，提示词不会发送，会原样回到输入栏，高亮也会保留；如果这期间你已在输入栏中输入了别的内容，则不会覆盖。

只有当这个快捷指令仍从同一个文件、为会话的工作目录加载时，命令才会运行。如果之后换了工作目录，或移动、删除了快捷指令文件，命令不会运行：提示词会作为普通文本回到输入栏，再次发送时按原文发送。

只要发送时会运行命令，输入栏上方的卡片就会显示条数，例如 `发送时运行输入栏中的 2 条命令`。

任务运行期间，会运行命令或切换智能体、模型的提示词不会发送：它留在输入栏中，等任务结束后再发送。只切换、不运行命令的提示词可以先点击“✕ 不切换”，再原样加入正在运行的任务。

这样的提示词总是开始一个新的轮次。任务停止或失败后，按 **Enter** 发送它；**继续**按钮会把输入栏中的内容作为备注原样发送，所以它不会发送这样的提示词。

选中快捷指令后，在你清空或替换输入栏内容之前，无论怎样编辑，它都算这个快捷指令的提示词。按 **Enter** 时输入栏中能看到的每个 `` !`…` `` 都会运行，包括你自己输入或粘贴的。不经过快捷指令、自己输入的消息不会运行命令。

### 智能体和模型

快捷指令设置的 `agent` 或 `model` 与当前不同时，输入栏上方会显示一张卡片，列出变化，例如 `Code → QA`。发送时，本会话会先切换过去，并在本会话中一直沿用；即使提示词随后没有发送，切换也会保留。新建会话（`/new` 或 `/clear`）使用新会话的智能体和模型：你最近用 `#` 选择（或启动时使用）的智能体，以及你的默认模型。

如果不想切换，点击卡片上的“✕ 不切换”后再发送。自己用 `#` 选择智能体或用 `$` 选择模型，也会取代卡片的切换。文件中写的智能体或模型找不到时，卡片会提示，发送时沿用当前的设置。设置了专用模型的智能体始终使用该模型：快捷指令写的模型与之不同时，会提示该模型未生效，提示词用智能体自己的模型发送，本会话之后也不会沿用快捷指令的模型。
