iCode Browser Bridge is installed

iCode can drive a tab it owns in your real browser, using the logins you already have. It never touches your other tabs.

Checking the bridge…
  1. Run iCode with the browser plugin. The plugin starts a local bridge; this page shows “Connected” when it is ready.
  2. Allow the first site. The first navigation returns site_permission_required. Open the extension popup, allow the origin, then retry.
  3. Manage sites. The options page sets the default for unknown origins, edits overrides, and imports/exports permissions.
